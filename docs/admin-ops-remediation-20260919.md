## Operations consolidation

`worker/infra/deploy.sh` is now the canonical **existing-production upgrade** entry point. It requires a full `REVIEWED_REVISION`, explicit `AUDITLAYER_REPO_DIR`, and absolute executable `DRAIN_HOOK`. It rejects a dirty/different checkout, old enabled/active singleton/PDF units, and an unexpected loaded local worker topology.

It archives the reviewed commit to an isolated staging directory, installs frozen dependencies, runs that archive's web unit/type checks and worker unit/S06 checks, validates migrations, runs the explicit drain hook, verifies both instances inactive, then creates a rollback snapshot **before** overwriting anything. It syncs the tested worker and versioned profile bundle into `/opt/auditlayer`, preserving `.env`, `.venv` and runtime `var/`; installs frozen embedded production dependencies; compares staged/deployed source and bundle; runs read-only preflight; checks effective service user/working directory/ExecStart; starts the two instances and checks both health endpoints. No inference smoke call remains.

The template unit now executes `/opt/auditlayer/worker/.venv/bin/python` directly, avoiding dependency resolution at service start. `Makefile` no longer installs the VM singleton; `check-v2` includes `pnpm test` and frozen web install. Bootstrap is development-only, uses frozen embedded+dev extras, requires explicit `HERMES_MODE=inprocess`, and does not rewrite credentials, provider linkage, shell startup, or services. Development credential sync requires explicit host and confirmation.

Retired singleton units are archived as `.service.example` under `worker/infra/archive/`. Duplicate root WSGI units/env example were removed; `infra/systemd/README.md` identifies `legacy/infra/systemd/` as the historical application, not a production option. The release-evidence rollback checklist now references fleet draining and the actual template instances rather than restarting a stale singleton.

Preflight verifies RPC argument-name sets using **OpenAPI GET only**, not trial mutating calls. Contracts were derived from current migration definitions and are checked against those files by a test. Coverage includes initial/refinement/regeneration finalization, entitled batch submission, Instagram worker write fencing, both new admin RPCs, and the concurrently added refinement enqueue/sweep RPCs. It also probes the corresponding version/refinement/credential-version columns with zero-row selects. The provenance static test now checks relative W014/W015 ordering instead of requiring its historical migration to remain globally latest.
