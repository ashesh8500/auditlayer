# AuditLayer Autonomous Improvements

This directory is the source of truth for the bounded `alm-build` mission.

Read in order:

1. `VISION.md` — north star and eight improvement programs.
2. `FUNDAMENTALS.md` — non-negotiable epistemic, product, safety, and engineering constraints.
3. `USER-STORIES.md` — creator, founder, and developer outcomes every idea must serve.
4. `IDEA-QUEUE.md` — append-only proposed/in-flight work.
5. `LEDGER.md` — append-only verified, failed, partial, and parked verdicts.

The mission works only on `improve/alm-recursive-2026-08-07` and isolated `wt/almbuild-*` worktrees. It never deploys, migrates production, restarts services, spends live report tokens, or mutates customer data. An independent human-approved release path remains responsible for production promotion.
